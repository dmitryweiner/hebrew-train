# Тестирование

```bash
npx vitest run            # все тесты один раз
npm test                  # watch-режим
npx vitest run src/core   # только ядро обучения
```

## Что покрыто

| Где | Что проверяется |
|-----|-----------------|
| `src/core/__tests__/` | Коробки Лейтнера, сроки повторения, серия дней, звёзды; выбор слов и «Тренировка дня»; раунд с повторами после ошибок и итогами; хранилище и миграция старой статистики |
| `src/data/__tests__/` | Словарь: уникальные id и эмодзи, наличие картинок, огласовки совпадают с написанием, мнемоники и теги |
| `src/games/__tests__/` | Каждая игра: правильный ответ, ошибка, завершение задания |
| `src/pages/__tests__/` | Раунд целиком до итогов с записью прогресса, подтверждение выхода, настройки, страница прогресса |
| `src/pwa/__tests__/` | Резервная копия: экспорт, импорт, отказ на чужом файле |
| `src/utils/__tests__/` | Работа с ивритом (конечные формы, гереш, позиции букв), дистракторы, склонение |

## Что проверять руками

- Установка на Android и iPhone, запуск в авиарежиме, баннер «Доступна новая версия».
- Голос иврита: на Android — «Синтезатор речи Google» с ивритом, на iPhone — голос Carmit.
- Внешний вид новых эмодзи на старых Android (🫑 🫒 🪣 🪨 появились в Android 11).
