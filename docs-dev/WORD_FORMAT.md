# Формат данных для слов

## Структура Word

Каждое слово в приложении Hebrew Train имеет следующую структуру:

```typescript
interface Word {
  id: string;                    // уникальный идентификатор
  emoji?: string;                // эмодзи символ (опционально, если есть picture)
  picture?: string;              // путь к SVG картинке (опционально, если есть emoji)
  hebrew: string;                // слово на иврите
  russian: string;               // перевод на русский
  transliteration: string;       // латинская транслитерация
  category: string;              // категория (food, animals, transport, etc.)
  audioUrl?: string;             // опционально: ссылка на аудио произношения
  frequencyRank?: number;        // опционально: частотность слова в иврите
}
```

## Примеры

### Слово с эмодзи

```json
{
  "id": "apple",
  "emoji": "🍎",
  "hebrew": "תפוח",
  "russian": "яблоко",
  "transliteration": "tapuach",
  "category": "food"
}
```

### Слово с картинкой

```json
{
  "id": "table",
  "picture": "table.svg",
  "hebrew": "שולחן",
  "russian": "стол",
  "transliteration": "shulchan",
  "category": "home"
}
```

## Важные правила

1. **Эмодзи ИЛИ картинка**: Каждое слово должно иметь **либо** поле `emoji`, **либо** поле `picture`, но не оба одновременно.

2. **Путь к картинкам**: Все картинки (SVG, PNG и др.) должны находиться в папке `public/pictures/`. В поле `picture` указывается только имя файла (например, `"table.svg"`), а не полный путь.

3. **Формат картинок**: Рекомендуется использовать SVG формат для картинок, так как он масштабируется без потери качества.

4. **Размеры**: Картинки будут автоматически масштабироваться до размеров 100-140px в зависимости от контекста использования.

## Категории слов

- `food` - Еда и напитки
- `animals` - Животные
- `home` - Дом и быт
- `objects` - Предметы
- `nature` - Природа
- `transport` - Транспорт
- `clothes` - Одежда
- `body` - Части тела

## Уровни сложности

- `1` - Простое слово (короткое, частотное)
- `2` - Среднее слово
- `3` - Сложное слово (длинное, редкое)

## Добавление новых слов

Чтобы добавить новое слово:

1. Если используете картинку, сначала поместите файл в `public/pictures/`
2. Откройте `src/data/words.json`
3. Добавьте новый объект в массив
4. Убедитесь, что:
   - `id` уникален
   - Есть либо `emoji`, либо `picture`
   - Если используется картинка, файл существует в `public/pictures/`
   - Все обязательные поля заполнены

## Компонент отображения

Для отображения эмодзи или картинки используется компонент `WordImage`:

```tsx
import WordImage from '../WordImage';

// Использование
<WordImage 
  emoji={word.emoji} 
  picture={word.picture} 
  alt={word.russian} 
  size="large" 
/>
```

Компонент автоматически определяет, что отображать - эмодзи или картинку, и применяет соответствующие стили.
