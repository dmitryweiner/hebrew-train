# Формат слова в `src/data/words.json`

```json
{
  "id": "apple",
  "emoji": "🍎",
  "hebrew": "תפוח",
  "nikud": "תַּפּוּחַ",
  "russian": "яблоко",
  "transliteration": "tapuach",
  "category": "food",
  "tags": ["fruits"],
  "mnemonic": "ТАПУАХ — яблоко упало с ветки: «тап!» — «ух!»"
}
```

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `id` | да | Латиница, цифры и `_`. Уникален: по нему хранится прогресс, менять нельзя |
| `emoji` / `picture` | одно из двух | Эмодзи (не должен повторяться у разных слов) или файл из `public/pictures/` |
| `hebrew` | да | Слово без огласовок, полное написание. Только буквы, пробел и гереш `׳` |
| `nikud` | да | То же слово с огласовками. Без огласовок должно совпадать с `hebrew` буква в букву |
| `russian` | да | Перевод |
| `transliteration` | да | Латинская транслитерация |
| `category` | да | Одна из тем в `src/data/categories.ts` |
| `tags` | да | Тематические наборы латиницей: `kitchen`, `fruits`, `stationery`… |
| `mnemonic` | да | Короткая ассоциация на русском для запоминания |

Все правила проверяет тест `src/data/__tests__/words.test.ts` — запустите `npx vitest run src/data` после правки.

## Картинки вместо эмодзи

Если подходящего эмодзи нет или он двусмысленный, положите SVG/PNG (примерно 128–512 px, прозрачный фон) в `public/pictures/` и укажите `"picture": "file.svg"` вместо `emoji`. Картинки попадают в кэш service worker и доступны оффлайн.

Для каждого эмодзи в `public/emoji/` лежит SVG-копия (Twemoji). Её показывают устройства, в шрифте которых этого эмодзи нет: на старых Android вместо новых эмодзи (Unicode 11+, например 🪑 или 🧑‍⚕️) рисуется квадрат с крестиком. После добавления слова с новым эмодзи запустите `node scripts/fetch-emoji.mjs`, иначе тест словаря упадёт.

## Новые слова

- Новые слова вводятся по очереди из разных тем (`interleaveByCategory` в `src/core/scheduler.ts`); внутри темы — сверху вниз по файлу.
- Только единственное число, без артикля `ה`.
