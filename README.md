# 🌟 Hebrew Train - Тренажёр по ивриту

Веб-приложение для изучения иврита, оптимизированное для пожилых пользователей с фокусом на мобильные устройства.

## 📋 Описание

Hebrew Train - это образовательное приложение, которое помогает изучать иврит через интерактивные игры с использованием эмодзи. Приложение разработано с учётом особенностей пожилой аудитории: крупные элементы интерфейса, высокая контрастность, простая навигация и понятная обратная связь.

## 🎮 Игры

### ✅ Реализованные (MVP)

1. **Буква (выбор)** - ⭐ *Реализовано*
   - Показывается эмодзи и слово с пропущенной буквой
   - Выберите правильную букву из 4-6 вариантов
   - Визуальная обратная связь (зелёный/красный)
   - Автопереход после правильного ответа
   - Самый простой уровень для начинающих

2. **Буква (ввод)** - ⭐⭐ *Реализовано*
   - Введите пропущенную букву с клавиатуры
   - Автоматическая проверка раскладки (иврит/не иврит)
   - До 2 попыток на каждое слово
   - Поддержка нормализации конечных форм букв
   - Тренировка ивритской раскладки

3. **Слово (выбор)** - ⭐⭐ *Реализовано*
   - Показывается эмодзи, выберите правильное слово
   - 3-4 варианта ответа
   - Умный подбор дистракторов (похожие слова)
   - Работа с полными словами

4. **Слово (ввод)** - ⭐⭐⭐ *Реализовано*
   - Напишите слово целиком с клавиатуры
   - До 3 попыток на каждое слово
   - Система подсказок (первая буква)
   - Индикатор длины слова
   - Полноценная работа с ивритской клавиатурой

### 🔄 Планируются

5. **Составь слово** - Соберите слово из перемешанных букв
6. **Найди пары** - Сопоставьте эмодзи со словами
7. **Проверь себя** - Быстрая проверка знаний (да/нет)

- **Frontend Framework**: React 18+
- **Language**: TypeScript
- **UI Framework**: Bootstrap 5
- **Build Tool**: Vite
- **State Management**: React Hooks + LocalStorage
- **Testing**: Vitest + React Testing Library

## 📱 Особенности

- ✅ **Mobile-first дизайн** - оптимизировано для смартфонов и планшетов
- ✅ **Крупные элементы** - минимальный размер кнопок 44×44px
- ✅ **Крупный шрифт** - минимум 18px для текста, 24px+ для заголовков
- ✅ **Высокая контрастность** - для лучшей читаемости
- ✅ **Нативная клавиатура** - тренировка на реальной клавиатуре устройства
- ✅ **Автоматическая проверка раскладки** - подсказки при вводе не на иврите
- ✅ **Умный переход к следующему вопросу** - кнопка "Дальше!" для нетерпеливых, автоматический переход через 4 сек
- ✅ **LocalStorage** - сохранение прогресса без регистрации
- ✅ **Без интернета после загрузки** - работает офлайн

Каждое слово содержит:
- **Эмодзи или SVG-картинку** для визуального представления

- Транслитерация латиницей

**Примечание**: Для некоторых слов, где подходящего эмодзи нет (например, "стол"), используются картинки (SVG, PNG). Картинки находятся в `public/pictures/` и автоматически копируются при сборке.

## 🚀 Быстрый старт

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd hebrew-train

# Установить зависимости
npm install
```

### Разработка

```bash
# Запустить dev-сервер
npm run dev
```

Приложение откроется на `http://localhost:5173`

### Тестирование

```bash
# Запустить тесты
npm test

# Запустить тесты в watch mode
npm test -- --watch

# Запустить тесты с UI
npm run test:ui

# Запустить тесты с покрытием
npm run test:coverage
```

### Сборка

```bash
# Собрать для продакшна (сборка в папку dist/)
npm run build

# Предпросмотр сборки
npm run preview
```

### Деплой на GitHub Pages

Деплой автоматический: на каждый push в `main` GitHub Actions (`.github/workflows/deploy.yml`) запускает lint, тесты и сборку, затем публикует папку `dist/` на GitHub Pages. В настройках репозитория источник Pages должен быть **GitHub Actions**.
