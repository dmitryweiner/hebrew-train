# 🌟 [Тренажёр иврита](https://dmitryweiner.github.io/hebrew-trainer/)
Тренажёр слов на иврите для русскоязычных пользователей, в первую очередь пожилых. Работает в браузере телефона, устанавливается на экран «Домой» и работает без интернета.

## Как это устроено

В центре — **личный словарь**. Каждое слово лежит в одной из коробок (упрощённая система Лейтнера):

| Коробка | Смысл | Когда повторять |
|---------|-------|-----------------|
| 0 | Новое | — |
| 1 | Познакомился | в тот же день |
| 2 | Узнаю | через 1 день |
| 3 | Помню | через 3 дня |
| 4 | Выучено | через 7 дней |
| 5 | Закреплено | через 30 дней |

Правильный ответ в срок поднимает слово на коробку выше, ошибка опускает на одну. Новые слова вводятся порциями по 5, по очереди из разных тем.

**Тренировка дня** — главная кнопка: новые слова через карточки и «Угадай букву», затем повторение по срокам в разных играх. Серия дней подряд 🔥 на главном экране.

Любая игра идёт раундом с полоской заданий и заканчивается экраном итогов: звёзды, список слов с ✓/✗, кнопка «Повторить ошибки».

## 🎮 Игры

| Игра | Что делаем | Для каких слов |
|------|------------|----------------|
| 📇 Карточки | Картинка → показать слово → «Знал / Не знал» | новые и любые |
| 🔤 Угадай букву | Выбрать пропущенную букву | новые (в «Тренировке дня») |
| 🔗 Найди пары | Соединить 5 картинок с 5 словами | любые |
| 🖼️ Угадай слово | Картинка и 4 слова | любые |
| 🧩 Собери слово | Слово из плиток-букв (+2 лишние) | знакомые |
| 🃏 Мемори | Найти пары «картинка — слово» среди закрытых карточек | любые |
| ⚡ Верно или нет | 60 секунд, рекорд | любые |
| 👂 Послушай и выбери | Услышать слово и найти картинку | если есть голос иврита |
| ✍️ Напиши слово | Написать слово целиком, системной или экранной клавиатурой | хорошо знакомые |

## 📱 Для пожилых пользователей

- Крупные кнопки и шрифт, настройка размера текста «A / A+ / A++».
- Экранная ивритская клавиатура в стандартной раскладке (включается в настройках или прямо в задании): не нужно переключать раскладку телефона.
- Озвучка слов голосом иврита (синтез речи телефона, работает без интернета).
- Огласовки (никуд) и русская ассоциация-подсказка для каждого слова.
- После правильного ответа слово видно некоторое время (0,5–3 с, по умолчанию 1 с), затем открывается следующее задание; автопереход можно выключить. После ошибки ответ не исчезает, пока не нажать «Дальше».
- Звуковой сигнал после правильного и неправильного ответа (выключается в настройках).
- Задания с письмом можно выключить в настройках.

## 📚 Словарь

257 слов в 11 темах: еда, животные, предметы, дом, природа, транспорт, одежда, тело, люди, город, цвета. Где нет понятного эмодзи, вместо него SVG-картинка из `public/pictures/`. Данные — в `src/data/words.json`, формат описан в [docs-dev/WORD_FORMAT.md](docs-dev/WORD_FORMAT.md). Словарь проверяется тестом `src/data/__tests__/words.test.ts`.

## 🔐 Приватность и данные

- Нет сервера, регистрации и аналитики.
- Прогресс хранится только в браузере (`localStorage`, ключ `hebrew-train/v2`).
- На странице «Прогресс» есть резервная копия: сохранить прогресс в файл и загрузить его на другом телефоне.

## 🛠 Разработка

Стек: React 19, TypeScript, Vite, Bootstrap 5, react-router (hash-режим), vite-plugin-pwa, Vitest + Testing Library.

```bash
npm install          # зависимости (публичный реестр npm)
npm run dev          # dev-сервер: http://localhost:5173
npx vitest run       # тесты
npm run lint         # ESLint
npm run build        # сборка в dist/ (с service worker)
npm run preview      # проверить сборку локально, в т.ч. оффлайн
```

Иконки PWA генерируются из `public/icon.svg`: `npx pwa-assets-generator`.

### Структура

```
src/
├── core/          # логика обучения без React: коробки, планировщик, раунд, хранилище, озвучка
├── state/         # контекст прогресса (useReducer поверх localStorage)
├── games/         # компоненты заданий: по одному на игру
├── components/    # общие компоненты: оболочка игры, итоги, карточка слова, клавиатура
├── pages/         # главная, раунд, прогресс, настройки
├── pwa/           # service worker, установка, резервная копия
├── data/          # словарь и названия тем
└── utils/         # работа с ивритом, перемешивание, склонение
```

### Деплой

На каждый push в `main` GitHub Actions (`.github/workflows/deploy.yml`) запускает lint, тесты и сборку, затем публикует `dist/` на GitHub Pages. Источник Pages в настройках репозитория — **GitHub Actions**.

План развития и принятые решения — в [PLAN-IMPROVEMENTS.md](PLAN-IMPROVEMENTS.md). История старых версий — в [docs-dev/history/](docs-dev/history/).
